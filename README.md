# FastAPI + SQLite + Docker + Nginx

Учебный проект для практики работы с:

- асинхронной SQLite через aiosqlite
- подключением и управлением базой данных в FastAPI
- Docker и Docker Compose
- Docker Volume для сохранения данных
- взаимодействием контейнеров через Docker Network
- Nginx как reverse proxy
- запуском backend-приложения в контейнере

Цель проекта — разобраться, как работают контейнеры, хранение данных, сетевое взаимодействие между сервисами и базовая backend-архитектура.

## Команды для Docker
- Docker logs {имя контейнера} --> посмотреть логи запущенного приложения, можно через ключ -f что бы смотреть в реальном времени
- Docker port {контейнер} --> какие порты проброшены
- Docker inspect {контейнер} --> посмотреть детальную информацию

## Про проект 
- оставлен reload , для перезапуска проекта при изменении файла, это происходит из за - .:/app в volumes --> мы используем bind mount, который монтирует директорию проекта с нашей машины в `/app` внутри контейнера. Поэтому изменения файлов на компьютере сразу видны внутри контейнера, и Uvicorn может их отслеживать.
